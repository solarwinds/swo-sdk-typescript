# AvailabilityCheckSettings

Use this field to configure availability tests for the website.

## Example Usage

```typescript
import { AvailabilityCheckSettings } from "@solarwinds/swo-sdk-typescript/models/components";

let value: AvailabilityCheckSettings = {
  testFrom: {
    type: "REGION",
    values: [
      "NA",
    ],
  },
  testIntervalInSeconds: 683.32,
  outageConfiguration: {
    failingTestLocations: "all",
    consecutiveForDown: 2,
  },
  protocols: [
    "HTTPS",
  ],
};
```
